## Админка

### Сайт и страницы
- [x] **Главная страница редактируется из админки.** (Step 121) Сейчас обычные (созданные владельцем) страницы редактируются, а системные — главная, тарифы, обратная связь — нет: данные не загружаются. Решение владельца (2026-10-13): главную открыть для редактирования; «Тарифы» и «Обратная связь» меняются только через код — в админке у них не должно быть сломанного редактора (только просмотр/настройки меню или понятная пометка «редактируется в коде»).
- [x] **Визуальный редактор вместо HTML-поля.** (Step 122, ADR 0045) Полноценный редактор для не-программистов, с подключённым Tailwind (предпросмотр в стилях сайта). Выбор редактора — через ADR.
- [x] **Готовые шаблоны блоков и секций** (Step 123, ADR 0046) (герой, преимущества, цены, FAQ, CTA и т. п.), вставляемые в страницу из редактора.
- [x] **Отдельный раздел «Шаблоны блоков»** (Step 124) — создание и редактирование этих шаблонов.

### Клиенты
- [x] **В блоке «Действия» кнопка «Напомнить о…»** (Step 125, ADR 0047): выбор из списка — подписка, оплата, другое; на e-mail клиента уходит выбранное письмо (шаблон). Аудит отправки.
- [x] **Раздел Магазины** (Step 126, ADR 0048), должно быть возможно добавить магазин, по клику на магазин, должно быть возможно просмотреть все данные "Находки, заказы и скриншоты, инциденты"
- [x] **Раздел Сотрудники**, должно быть возможно добавить сотрудника, так же как в кабинете компании (Step 127)
### Обращения
- [x] **Кнопка «Ответить»** (Step 128, ADR 0049): шаблон письма + тема + текст, отправка на e-mail обратившегося, ответ сохраняется в обращении.
- [x] **Внутренние заметки списком** (Step 129): каждая заметка сохраняется отдельно с датой и сотрудником, вместо одного поля «Внутренняя заметка».
