# Задачи от владельца (бэклог)

Записано 2026-10-13 после ручной проверки локального стенда. Пока не делать — брать по одной по выбору владельца. Выполненные пункты отмечать `[x]` с номером шага.

## Админка

### Сайт и страницы
- [ ] **Ошибка: редактирование страниц не работает — данные страницы не загружаются.** Воспроизвести на стенде, починить, добавить тест.
- [ ] **Понятнее отметка «юридический документ».** Сейчас тип задаётся в «Настройки страницы» → «Юридический документ» (Условия использования / Политика конфиденциальности / Условия подписки). Владелец этого не нашёл — сделать заметнее (например, при создании страницы и бейджем в списке/в шапке редактора).
- [ ] **Визуальный редактор вместо HTML-поля.** Полноценный редактор для не-программистов, с подключённым Tailwind (предпросмотр в стилях сайта). Выбор редактора — через ADR.
- [ ] **Готовые шаблоны блоков и секций** (герой, преимущества, цены, FAQ, CTA и т. п.), вставляемые в страницу из редактора.
- [ ] **Отдельный раздел «Шаблоны блоков»** — создание и редактирование этих шаблонов.
- [ ] **Страница «Тарифы» редактируемая из админки** (тексты вокруг сетки тарифов).

### Клиенты
- [ ] **В блоке «Действия» кнопка «Напомнить о…»**: выбор из списка — подписка, оплата, другое; на e-mail клиента уходит выбранное письмо (шаблон). Аудит отправки.

### Обращения
- [ ] **Кнопка «Ответить»**: шаблон письма + тема + текст, отправка на e-mail обратившегося, ответ сохраняется в обращении.
- [ ] **Внутренние заметки списком**: каждая заметка сохраняется отдельно с датой и сотрудником, вместо одного поля «Внутренняя заметка».
