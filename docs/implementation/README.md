# Исторические чек-листы реализации

Файлы `implementation-step-*.md` фиксируют состояние ранних шагов на момент их выполнения. Незакрытые пункты и фразы «не реализовано» внутри них не являются текущим бэклогом и не переписываются задним числом.

Текущее состояние — [PROJECT_STATE.md](../../PROJECT_STATE.md), задачи владельца — [backlog.md](../backlog.md), приёмка — [readiness.md](../readiness.md) и матрицы `spec/`, история поздних шагов — [progress.md](../progress.md).
