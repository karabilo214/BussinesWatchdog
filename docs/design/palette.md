# Корпоративная палитра Business Watchdog

Статус: **зафиксирована 2026-10-09** (ADR 0015). Источник — `apps/frontend/design/palette.json`; токены Tailwind — `apps/frontend/src/styles/palette.css`; `make frontend-palette-check` падает при любом изменении. Менять палитру можно только решением владельца с новым ADR.

## Принципы

- Финансовый мониторинг: спокойный корпоративный синий, без кричащих оттенков; цвет несёт смысл, а не украшает.
- **«Неизвестно» ≠ «в порядке».** Для отсутствия данных, неподключённых источников и неоконченных проверок есть отдельный серо-фиолетовый `unknown`. Он никогда не зелёный и не выглядит как выключенный элемент.
- Цвет никогда не единственный носитель смысла: рядом всегда текст статуса и иконка (дальтонизм, печать, скриншоты).
- Все пары текст/фон ниже проверены на WCAG 2.1 AA (≥ 4.5:1 для обычного текста).
- Стандартные цвета Tailwind отключены (`--color-*: initial`): в коде существуют только эти токены.

## Смысловые токены (используются в компонентах)

| Токен | Значение | Назначение |
|---|---|---|
| `canvas` | `ink-50` | фон приложения |
| `surface` | `white` | карточки, таблицы |
| `surface-muted` | `ink-100` | выделенные области |
| `border` | `ink-200` | рамки |
| `border-strong` | `ink-300` | рамки полей ввода |
| `text` | `ink-950` | основной текст |
| `text-muted` | `ink-600` | вторичный текст (≥ 4.5:1) |
| `text-subtle` | `ink-500` | только крупный текст и иконки (3.65:1) |
| `primary` | `brand-700` | основная кнопка, текст на ней белый (7.38:1) |
| `primary-hover` | `brand-800` | наведение |
| `primary-soft` | `brand-50` | выбранный пункт меню |
| `link` | `brand-600` | ссылки (5.34:1) |
| `focus` | `brand-500` | кольцо фокуса клавиатуры |
| `ok / ok-soft / ok-border / ok-solid` | `success-700 / 50 / 200 / 600` | в порядке, проверка пройдена, сверка ok |
| `warn / …` | `warning-700 / 50 / 200 / 600` | предупреждение, данные устарели, задержка |
| `crit / …` | `danger-700 / 50 / 200 / 600` | критично, подтверждённый сбой, расхождение денег |
| `note / …` | `info-700 / 50 / 200 / 600` | информация, проблемы самой проверки |
| `unknown / …` | `unknown-700 / 50 / 200 / 600` | неизвестно, нет данных, не подключено, неопределённый результат |

Значок статуса: фон `*-soft`, текст `*` (оттенок 700), рамка `*-border`. Сплошная плашка: фон `*-solid` (600), текст белый. Проверенный контраст: 700 на 50 ≥ 6.9:1, белый на 600 ≥ 4.97:1.

|---|---|

| Инцидент `warning` | `warn` |

| Проверка `failed` | `crit` |
| Проверка `blocked` / `unsupported` (проблема самой проверки) | `note` |
| Проверка `inconclusive` / `queued` / `running` | `unknown` |
| Коннектор `fresh` | `ok` |
| Коннектор `partial` | `warn` |
