## Что осталось до первых продаж и после них

1. **Paddle включает checkout** (внешнее): завершить онбординг продавца; затем проверочная покупка Start и возврат через панель.
2. **Удаление данных клиента** (ACC-42, EXT): сейчас только вручную по запросу — нужен рабочий процесс до заметного числа клиентов.
3. **Поддержка по гранту** (EXT-05/06): доступ сотрудника к данным клиента только с разрешением клиента.
4. **Эксплуатационные проверки**: восстановление на новом сервере (ACC-41), нагрузочный тест и второй воркер (ACC-43, ADR 0066), проверки падения БД/Redis.
5. **Приёмка денег**: реестр FIN-01…24 (ACC-29).
6. **Юридическое**: проверка текстов юристом, вопрос представителя в ЕС.
7. **§43** — решение владельца, когда браться; до этого функция не продаётся.
