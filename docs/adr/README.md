# Архитектурные решения

Принятые решения хранятся в отдельных ADR этого каталога; исходные требования и открытые вопросы внутри ADR читаются вместе с его последующими уточнениями, текущим бэклогом и историей реализации. Наличие принятого ADR не означает, что функция реализована или выложена.

Актуальные точки входа на 2026-10-29:

- [0007 — наблюдение попыток оплаты](0007-payment-attempt-monitoring.md): реализованные слои 1–2; аудит для расширения задачи 12 выполнен в Step 323, [отчёт](../checkout-monitoring-audit.md).
- [0077 — API-first подключения](0077-api-first-connections-and-woocommerce-webhooks.md).
- [0080 — выкладка без простоя](0080-zero-downtime-deploy.md): миграции совместимы с предыдущим выпуском.
- [0084 — подключение из WooCommerce и воронка](0084-plugin-one-click-connect-and-funnel.md): 0.4.2 опубликован, живая приёмка за владельцем.
- [0085 — заголовки безопасности](0085-browser-security-headers.md): локально готово, production-проверки открыты.
- [0086 — окна магазина](0086-store-dialogs-in-browser-checks.md), [0087 — ротация браузеров](0087-browser-rotation.md), [0088 — сторонние ресурсы](0088-third-party-reads-trackers-and-providers.md), [0089 — товар с корзиной и 5xx](0089-product-page-with-cart-and-store-server-errors.md): локальные изменения браузерных проверок, не выложены.
- [0090 — воронка настоящих покупателей](0090-checkout-funnel-of-real-customers.md): решение 2026-10-30 — только агрегаты без session IDs, ступени 7/14/28 дней; реализация начата с диагностики истории.

- [0091 — наблюдаемая история перед нормой](0091-sales-history-before-baseline.md): read-only диагностика; историческое покрытие unknown, тревоги ещё не включены.

- [0092 — покрытие заказов и исключения](0092-sales-coverage-and-exclusions.md): полные API-чтения + барьер проекций, компактный журнал и пометки локальных дней; статистические тревоги ещё выключены.

- [0093 — пригодные дни прогрева](0093-sales-warmup-eligible-local-days.md): диагностические ступени 7/14/28 для созданных заказов, без включения тревог.

- [0094 — пометки дней в кабинете](0094-sales-day-annotations-in-customer-panel.md): акции/праздники по дате и live/test с правами и аудитом; автоматический календарь DE ещё открыт.

- [0095 — календарь DE для нормы](0095-german-sales-holiday-calendar.md): явный регион/местные флажки, проверенные 2026–2027, праздники и воскресные метаданные без включения тревог.
- [0096 — диагностическая норма по окнам](0096-diagnostic-sales-baseline-bands.md): сопоставимые weekdays/воскресенья, точные медиана/MAD, окна 1/2/12/24 часа, явные ограничения DST и отсутствие калибровки.
- [0097 — точные DST-окна нормы](0097-exact-sales-dst-bands.md): реальные UTC-интервалы, отдельные повторения часа, структурные пропуски, сопоставимость длительности без ослабления покрытия.
- [0098 — профиль раннего прогрева](0098-early-sales-warmup-profile.md): парные суточные/часовые счётчики, уровень нужного weekday, кандидаты 7/14/28 без произвольных весов и статистической готовности.
- [0099 — выбор окна по объёму](0099-diagnostic-sales-window-volume-selection.md): 1/2/12/24 часа, явный draft min_expected_orders=20, точные сравнения всех кандидатов и abstain без статистической готовности.

Статусы выпуска — в [PROJECT_STATE.md](../../PROJECT_STATE.md), история — в [progress](../progress.md), задачи владельца — в [бэклоге](../backlog.md).
