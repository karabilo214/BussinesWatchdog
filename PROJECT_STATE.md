## Что это за проект

Business Watchdog — SaaS для обнаружения финансовых расхождений и поломок checkout в интернет-магазинах (рынок — Германия/DACH). Laravel модульный монолит + коннекторы магазинов + read-only коннекторы платёжных провайдеров + изолированный Playwright-воркер + подписка через Paddle. ИИ не реализуется.

## Что сделано (кратко, подробности — в `docs/progress/`)

- **Ядро** (`progress/core.md`): Docker-окружение, auth/tenancy, магазины, pairing и подтверждение, приём событий с идемпотентностью, outbox, аудит (хранение 2 года, ADR 0053), OpenAPI со сверкой маршрутов, «Сервис» с оповещениями (ADR 0051), окно обслуживания (ADR 0054), удаление организации (ADR 0069), боевой сервер, бэкапы, почта, CI.
- **Сверка и инциденты** (`progress/reconciliation.md`): проекции, allocations, правила сверки v3 (ADR 0068; реестр FIN-01…24 — `docs/reconciliation-registry.md`), движок инцидентов, режимы live/test (ADR 0018), параллельная синхронизация (ADR 0040), атрибуция платежей по магазинам (ADR 0073).
- **Коннекторы** (`progress/connectors.md`): WooCommerce-плагин и REST API, Shopware 6.6/6.7 (ключ интеграции и App, наблюдение за оплатами и оформлением, обновление App), Stripe (ограниченный ключ; OAuth удалён — недоступно для Украины) и PayPal только чтение.
- **Браузерные проверки** (`progress/browser-checks.md`): Playwright-воркер, синтетический маркер, egress-прокси, скриншоты без PII; WooCommerce и Shopware (ADR 0055), сверка товара/суммы/доставки/оплаты, честный пропуск шага оплаты (ADR 0070).
- **Уведомления** (`progress/notifications.md`): email, Telegram, напоминания, ежедневная сводка (ADR 0067), DKIM/SPF/DMARC.
- **Экспорты** (`progress/exports.md`): CSV findings/incidents/transactions со сроком хранения.
- **Кабинет клиента** (`progress/dashboard.md`): все экраны магазина, обзор, команда, MFA (предупреждение и сброс, ADR 0021), скрытие сумм от ролей.
- **Подписка и админка** (`progress/billing.md`): тарифы и пакеты, Paddle, пробный период на домен, скидки (сгорание), смена/отмена, пауза (полная пауза магазинов сверх лимита, ADR 0037), счета, возвраты, напоминания клиентам (ADR 0047), действия поддержки и команда клиента (ADR 0048), «Обзор» с KPI/MRR (ADR 0050), сотрудники платформы и их права (ADR 0052, 0064).

## Ждут решения владельца / внешних ответов

- WordPress.org: ZIP 0.3.3 отправлен, ручная проверка не завершена (подтверждено владельцем 2026-10-26). Локальная 0.3.4 не заменяет эту заявку; публикация или обновление заявки — отдельное действие владельца.
- Юридические документы (условия, политика, возвраты, Impressum) с 2026-10-21 ведёт юрист владельца; сервис их сам не правит.
- **ADR 0070 п. 2**: полная проверка формы оплаты как настройка проверки (разрешить известные origin провайдеров) — нужен отдельный дизайн и решение.
- Состав расширения шаблонов блоков.
- Политика конфиденциальности: упомянуть хранимые после удаления организации платёжные записи и хеши доменов (Step 204).
- Домен: `businesswatchdog.de` свободен, можно взять дополнительно; `businesswatchdog.com` не покупать до выручки.

## Не сделано / известные пробелы

- Подписка: конверсия пробных периодов и drill-down в «Обзоре», письма-напоминания об оплате, удаление заказов/платежей сверх срока хранения (сейчас только скрываются), живая проверка доплаты «частые проверки». Полный live-цикл покупки, отмены и одобренного возврата подтверждён владельцем 2026-10-22.
- Наблюдение checkout: страница order-pay, статистическое правило доли успешных оплат (ADR 0007); ADR 0006 п. 2.
- Из каталога UI (`contracts/ui-api-catalog.md` §11): создание/переключение команд, maintenance windows, rules.
- Система обязательств §43 не реализована. Перед заявлением полного покрытия §18 нужен плановый lease на подключённом магазине.
- Из исследования платформ: экспорт диагностики с согласием, бюджет производительности checkout, совместимость с кеширующими/защитными плагинами; Shopify — следующая платформа по спросу.
- PayPal: настоящий подписанный webhook не проверялся. PayPal Payments ограничивает выдачу client token (429) при повторных проверках с одного IP.
- Shopware: частичный возврат SwagPayPal остаётся `unknown` (магазин не отдаёт сумму возврата).
- Тестовые магазины (Step 206): не сделаны удаление App и WooCommerce PayPal с тестовым покупателем; магазины без системного cron замолкают при низком трафике.
- Платежи общего аккаунта без признаков магазина не разделяются (ADR 0073).
- Память backend-тестов растёт ~0,2 МБ на тест (лимит 512M в `phpunit.xml`, причина не искалась).
- `spec/PANELS-ACCEPTANCE.md` / `spec/ACCEPTANCE.md` — продолжать обновлять при закрытии acceptance-пунктов.
