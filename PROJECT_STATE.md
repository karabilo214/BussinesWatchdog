## Что это за проект

Business Watchdog — SaaS для обнаружения финансовых расхождений и поломок checkout в интернет-магазинах (рынок — Германия/DACH). Laravel модульный монолит + коннекторы магазинов + read-only коннекторы платёжных провайдеров + изолированный Playwright-воркер + подписка через Paddle. ИИ не реализуется.

## Ждут решения владельца / внешних ответов

- Юридические документы (условия, политика, возвраты, Impressum) с 2026-10-21 ведёт юрист владельца; сервис их сам не правит.
- **ADR 0070 п. 2**: полная проверка формы оплаты как настройка проверки (разрешить известные origin провайдеров) — нужен отдельный дизайн и решение.
- Одобрение версии Shopware App **1.4.0** (1.3.2 устарела): отпечаток (команда в `docs/ops/integrations.md`) в `WATCHDOG_SHOPWARE_APP_APPROVED_SHA256` — после выкладки App доступен всем клиентам (ADR 0074).
- Состав расширения шаблонов блоков.
- Политика конфиденциальности: упомянуть хранимые после удаления организации платёжные записи и хеши доменов (Step 204).
- Домен: `businesswatchdog.de` свободен, можно взять дополнительно; `businesswatchdog.com` не покупать до выручки.

## Не сделано / известные пробелы

- Подписка: конверсия пробных периодов и drill-down в «Обзоре», письма-напоминания об оплате, удаление заказов/платежей сверх срока хранения (сейчас только скрываются), живая проверка доплаты «частые проверки», одобрение возврата Paddle не наблюдалось.
- Наблюдение checkout: страница order-pay, статистическое правило доли успешных оплат (ADR 0007); ADR 0006 п. 2.
- Из каталога UI (`contracts/ui-api-catalog.md` §11): создание/переключение команд, maintenance windows, rules.
- Система обязательств §43 не реализована. Перед заявлением полного покрытия §18 нужен плановый lease на подключённом магазине.
- Из исследования платформ: экспорт диагностики с согласием, бюджет производительности checkout, совместимость с кеширующими/защитными плагинами; Shopify — следующая платформа по спросу.
- PayPal: настоящий подписанный webhook не проверялся. PayPal Payments ограничивает выдачу client token (429) при повторных проверках с одного IP.
- Shopware: частичный возврат SwagPayPal остаётся `unknown` (магазин не отдаёт сумму возврата).
- Тестовые магазины (Step 206): не сделаны удаление App и WooCommerce PayPal с тестовым покупателем; магазины без системного cron замолкают при низком трафике.
- Платежи общего аккаунта без признаков магазина не разделяются (ADR 0073).
- `spec/validate_spec.py` падает на проверке числа операций платёжного API.
- Память backend-тестов растёт ~0,2 МБ на тест (лимит 512M в `phpunit.xml`, причина не искалась).
- `spec/PANELS-ACCEPTANCE.md` / `spec/ACCEPTANCE.md` — продолжать обновлять при закрытии acceptance-пунктов.
