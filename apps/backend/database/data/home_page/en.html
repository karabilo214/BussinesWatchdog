How we handle data

Separate read permissions

Use a dedicated key with the required read permissions for WooCommerce and Shopware. For Stripe, use a restricted key. PayPal permissions depend on the available access model.

No payment management

Reconciliation does not create charges or issue refunds. Browser scenarios do not confirm real purchases.

Access can be revoked

Disable a store or provider key at its source. The corresponding monitoring coverage will stop receiving data.

Read access still needs trust

Read-only access still exposes records. Test a connector on a copy of your store first; we can clarify the requirements before you connect.

Questions before you connect

Do I need a plugin straight away?

No. Start with the public URL check. API connections are available for ongoing monitoring; additional signals may require a plugin or App.

Does this guarantee every customer can pay?

No. A browser checks a selected journey before purchase confirmation. Actual payment success requires evidence from a real payment.

What if data is missing?

An unavailable source or incomplete data is shown as a coverage limitation. It must not look like confirmation that everything is fine.

Where will I see issues?

In your dashboard: incidents, check results and available order and payment records. Configure alerts by email and Telegram.
